# Biblioteca de Jogos
Aplicação WEB desenvolvida em PHP com o objetivo de gerenciar uma biblioteca de jogos, contendo sistema de autenticação de usuários e operações de banco de dados vinculadas por chaves estrangeiras.

**Curso:** Análise e Desenvolvimento de Sistemas

**Semestre:** 5º semestre

**Disciplina:** Programação WEB

## 🛠 Tecnologias

* PHP
* MySQL (Banco de Dados)
* XAMPP (Servidor Apache)
* Apache NetBeans
* HTML/CSS

## 📌 Funcionalidades

* Autenticação de usuário no sistema (usando como referência a tabela usuário).
* Inserção de dados na tabela de escolha
* Consulta dos dados na tabela de escolha.
* Alteração dos dados na tabela de escolha (Atualização de descrição e status).
